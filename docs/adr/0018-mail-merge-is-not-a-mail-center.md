# Mail merge is send-only

Organizers need to mail many Programmbeiträge without server access, but a campaign archive or inbox would become a second mailbox. Mails schreiben is compose-and-send only: the trail is the Aktivität Comment (sender + subject) on each Programmbeitrag and the copy in IMAP Sent. There is no send history, reopen, or inbox in Intern. Organizer-initiated festival@ mail goes through this Intern page; there are no CLI mail scripts.
