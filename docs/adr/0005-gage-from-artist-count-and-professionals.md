# Gage from artist count and professionals

When setting Gage for a Programmbeitrag (especially Nachrücker on a vacated slot), derive the amount from the act’s own size and professionalism — not from whatever the previous act on that calendar hole was paid. Predecessor fees are only a weak sanity check.

Observed B-Side Festival 2026 practice for **hobby concerts** (`professionalParticipantsCount = 0`, not a professional booking):

| `participantCount` | typical Gage |
| ------------------ | ------------ |
| 1                  | 100 €        |
| 2                  | 150 €        |
| 3                  | 200 €        |
| 4+                 | 250 €        |

Larger special formats (e.g. choir) can sit above the 250 € band. Where some members are professional, peer Confirmed/WFC acts usually sit about **+55 € per professional** on the hobby base (n=3+1 → 255 €, n=4+1 → 305 €). Fully professional small acts and other exceptions exist — compare similar Confirmed peers before sending a Zusagemail.

Solo DJs are typically **100 €**; B2B/duo DJ sets often **150 €**. Always changelog `ApplicationFeeUpdated` when setting or changing Gage.
