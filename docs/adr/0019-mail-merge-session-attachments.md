# Mails schreiben may attach files; automatic mails do not

Organizers need to send a PDF or image with festival@ mail, but storing those files would turn Mails schreiben into a Vorlage library. A send may include up to three PDF, JPEG, or PNG files chosen in that compose session (10 MB total), the same files for every recipient. Automatic app mails stay text-only. The Aktivität Comment stays `Mail: »Betreff«`; IMAP Sent holds the real message including attachments.
